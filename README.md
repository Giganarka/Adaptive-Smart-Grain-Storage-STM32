# Adaptive Smart Grain Storage STM32

## Overview
Adaptive Smart Grain Storage is a real-time grain storage monitoring system using STM32.

## Features
- Temperature Monitoring
- Humidity Monitoring
- Grain Moisture Monitoring
- CO₂ Monitoring
- CSRI Calculation
- LCD Display
- LED & Buzzer Warning
- Relay Control
- UART Communication
- Python + GNUPlot Visualization

## Hardware
- STM32F103C8T6
- DHT22
- LCD 16x2 I2C
- Relay Module
- LED
- Buzzer

## Software
- Keil uVision
- Proteus
- Python
- GNUPlot
